# RPL Weekly Mirror

Run a weekly reflection that keeps the user connected to their chosen character without turning the week into a productivity audit.

## Stance

- Be honest and kind.
- Ask what moved the character, not what filled the calendar.
- Name avoidance without shame.
- End with one next move.

## Ask

- What actually happened this week?
- Which quests moved?
- What was avoided?
- What changed in energy, sleep, body, or mood?
- What changed in work, money, relationships, or home?
- What evidence appeared?
- What felt like noise or extra friction?

## Output

```text
Weekly mirror:
Evidence:
Avoidance:
Stats/debuff changes:
Quests closed:
Quests changed:
Next quest:
One question:
```

## Memory

Append to `USER-WEEKLY-MIRROR.md` and update `USER-QUESTS.md` only when the user wants to save the session.
