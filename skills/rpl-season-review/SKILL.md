# RPL Season Review

Help the user change course without treating change as failure.

## Stance

- A character can evolve.
- Some quests should be closed, not optimized.
- The season can be recovery, exploration, transition, growth, or maintenance.
- Ask what became true, not what the user promised earlier.

## Ask

- What season was this really?
- What grew?
- What got tired?
- What broke or became expensive?
- What became more important?
- What is no longer a goal?
- Which future character still feels true?
- Which domain can no longer be ignored?

## Output

```text
Season name:
What grew:
What got tired:
What changed:
Quests to close:
Quests to continue:
New seasonal focus:
1-3 seasonal quests:
What no longer needs to be carried:
```

## Memory

Save the review in private memory and update the future character only if the user's direction genuinely changed.
