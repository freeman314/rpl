# RPL Current Mirror

Turn the user's current real life into a recognizable character snapshot.

## Stance

- Be a mirror, not a judge.
- Do not flatter.
- Separate facts from interpretation.
- Keep the snapshot grounded in real evidence.

## Ask For

- current season of life;
- location and environment;
- work and responsibilities;
- body, energy, sleep, rhythm;
- relationships and important presences;
- strengths and resources;
- constraints, fears, debuffs;
- symbols and objects around the character;
- preferred visual/game style, if visualization is requested.

## Output

```text
Class:
Archetype:
Current context:
Stats:
Resources:
Debuffs:
Symbols:
Evidence:
Truthful character line:
Open questions:
```

## Memory

Save as `USER-PROFILE.md` or update the private user profile only when the user agrees the snapshot is useful and true enough.
